# Task

Create `/app/main.typ` — a two-page (or longer) document whose footer shows
"Page X of N" on every page, where N is the total page count of the document.

The total must be computed from the document itself, not hard-coded: if content
is added later and the page count changes, the footer must follow without
editing the footer code.

Compile the document to `/app/main.pdf`.
